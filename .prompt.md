# Run this project

You are helping a developer run the missing-person detection project in this workspace.

## Goal
Explain the exact steps to install dependencies, start the backend, open the dashboard, and enroll a person if needed.

## Project context
- Python project in the current workspace
- Main app entry is FastAPI in `main.py`
- Database/index logic lives in `database.py`
- Enrollment script is `enroll.py`
- Frontend alert dashboard is `index.html`
- Python dependencies are listed in `requirements.txt`
- The app uses the local webcam by default (`CAMERA_SOURCE = 0` in `main.py`)

## Instructions
1. Open a terminal in the workspace root.
2. Create and activate a virtual environment if needed.
3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Start the backend:
   ```bash
   python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```
5. Open `index.html` in a browser to view alerts.
6. If the app is being used for the first time, enroll a missing person before running live matching:
   ```bash
   python enroll.py --image "path/to/person.jpg" --name "John Doe" --age 30 --gender "Male" --contact "1234567890"
   ```
7. Keep the webcam available. If the project should use a different camera or RTSP source, change `CAMERA_SOURCE` in `main.py`.

## Expected behavior
- The backend starts the webcam loop automatically on startup.
- When a face matches a stored person above the threshold, the app broadcasts an alert over WebSocket.
- The browser dashboard updates in real time without polling.

## Troubleshooting
- If imports fail, install requirements again in the active environment.
- If no camera is detected, check the camera index or replace it with an RTSP URL.
- If matching is poor, adjust `MATCH_THRESHOLD` in `main.py`.
- If the browser cannot connect, ensure the backend is still running on port 8000.
